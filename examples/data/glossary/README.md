# Synthetic Demo Glossary

- `terms/<id>.md` is canonical; one file per term, ids never change.
- `generated/` is derived (open `generated/site/index.html` offline).
- `rules/profile.yaml` is the rule set; swap it per repo.
- Scripts live in the business-glossary skill; see the Makefile.
